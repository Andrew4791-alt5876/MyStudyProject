# Учебный проект по Python

## Описание:

Новая фича для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Andrew4791-alt5876/MyStudyProject.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем PyCharm.
2. Проект в стадии разработки.
