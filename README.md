## 📖 Описание

Новая фича для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента.

**Основные возможности:**
- ✅ Генерация номеров банковских карт
- ✅ Валидация входных данных
- ✅ Конвертация валюты по актуальному курсу
- ✅ Гибкая настройка диапазона
- ✅ Обработка ошибок

## 🚀 Функциональность

### Основные функции:
1. **card_number_generator()** - генератор номеров карт
   - Принимает начальный и конечный номер
   - Форматирует вывод в стандартный вид (XXXX XXXX XXXX XXXX)
   - Автоматически добавляет ведущие нули

2. **Особенности:**
   - Проверка корректности входных данных
   - Защита от некорректного ввода
   - Логирование ошибок

## 🎯 Использование:

### Базовый пример:
```
from src.generators import card_number_generator

# Создание генератора
gen = card_number_generator(1000, 1010)

# Получение номеров карт
for _ in range(5):
    card_number = next(gen)
    print(card_number)
```

### Параметры функции:
```
def card_number_generator(
    start_number: int,  # Начальный номер
    finish_number: int  # Конечный номер
) -> Generator[str]:
    """
    Генерирует номера банковских карт в заданном диапазоне.
    
    Args:
        start_number: Начало диапазона (включительно)
        finish_number: Конец диапазона (включительно)
    
    Returns:
        Generator: Генератор строк с номерами карт
        
    Raises:
        ValueError: При некорректных входных данных
    """
```

## 📝 Примеры:

### Пример 1: Простая генерация:
```
from src.generators import card_number_generator

# Генерация 10 номеров карт
gen = card_number_generator(1, 10)

for card in gen:
    print(card)
# Вывод:
# 0000 0000 0000 0001
# 0000 0000 0000 0002
# ...
# 0000 0000 0000 0010
```

### Пример 2: Обработка ошибок:
```
try:
    gen = card_number_generator(-5, 10)  # Отрицательное число
    print(next(gen))
except Exception as e:
    print(f"Ошибка: {e}")
```

### Пример 3: Использование в цикле:
```
# Генерация 100 номеров карт начиная с 999999
start = 999900
end = 999999

for card in card_number_generator(start, end):
    if "9999 99" in card:
        print(f"Найден специальный номер: {card}")
```

## Тестирование:

1. Запуск всех тестов:
```
pytest
```
2. Запуск с детальным выводом:
```
pytest -v
```
3. Запуск конкретного тестового файла
```
pytest tests/test_widget.py
```
4. Запуск конкретного теста:
```
pytest tests/test_widget.py::test_get_date -v
```
5. Запуск с покрытием кода:
```
pytest --cov=src --cov-report=html
```
6. Создание отчета о проверке:
```
poetry run pytest --cov
```
7. Расположение отчета в HTML-формате: 
```
В папке 'htmlcov' в модуле 'index.html'
```
